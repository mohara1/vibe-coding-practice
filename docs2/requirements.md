# 진주청년 — 요구사항 명세

> [기획안(plan.md)](./plan.md) 기반. 이 문서는 **개발 착수용 명세**다.

## 전제

- **프로토타입이다.** 공공데이터 API 연동·크롤링을 하지 않는다. 데이터는 **손으로 작성한 정적 JSON 파일** 하나로 끝낸다.
- **로그인·서버·DB 없음.** 사용자 정보는 브라우저에만 남는다.
- **모바일 우선.** 심사위원은 휴대폰으로 본다. PC는 가운데 정렬된 좁은 폭이면 충분하다.
- **톤:** 슥삭 스타일의 친근·캐주얼. 관공서 문체 금지.
- **목업 데이터 분량:** 최소 20건, 권장 30건. 그중 **진주시 출처 최소 8건** (도 정책만 있으면 "진주청년"이라는 이름이 무색해진다).

## 1. 화면 목록

화면은 3개다. 그 이상 만들지 않는다.

### S1. 홈 — 카드 피드 `/`

메인 화면. 여기서 서비스의 승부가 난다.

| 영역 | 보이는 것 |
|---|---|
| 헤더 | 서비스명 `진주청년` + 한 줄 태그라인 (예: "진주 청년이 받을 수 있는 것만 모았어요") |
| 내 조건 배너 | 온보딩을 했을 때만 표시. `24살 · 진주 거주 · 대학생 기준으로 보는 중` + `조건 바꾸기` 버튼 |
| 필터칩 | `전체` `일자리` `주거` `교육` `복지·문화` `금융` — 가로 스크롤. 선택된 칩만 채움 색 |
| 카드 리스트 | 세로로 흐르는 정책 카드. **표·게시판 형식 금지** |
| 빈 상태 | 필터 결과 0건일 때: "이 조건에 맞는 게 아직 없어요" + `필터 초기화` 버튼 |
| 푸터 | `2026년 8월 6일 기준` 갱신일(필수) · 출처 표기 · 면책 문구 |

**카드 1장에 들어가는 것 (6개, 순서 고정):**

1. `D-12` 마감 뱃지 — 7일 이내면 빨강, 그 외 회색. 상시모집은 `상시` 회색 뱃지
2. 분야 컬러칩 — 5개 분야마다 다른 색
3. 출처 뱃지 — `경남도` / `진주시`
4. 정책 이름
5. **한 줄 요약** — 카드에서 가장 크고 읽기 쉬운 요소. 이게 심장이다
6. 혜택 금액 강조 — `월 20만원` / `최대 300만원` / `무료`

**정렬:** 마감 임박순 → 상시모집 → (마감 지난 것은 표시하지 않음)

### S2. 상세 `/policy/[id]`

| 영역 | 보이는 것 |
|---|---|
| 상단 | 뒤로가기 · D-day 뱃지 · 분야칩 · 출처 뱃지 |
| 제목부 | 정책 이름 + **한 줄 요약** |
| 블록 1 | **누가 받나** — 나이·거주지·신분 조건 |
| 블록 2 | **얼마 받나** — 지원 내용과 금액 |
| 블록 3 | **어떻게 신청하나** — 신청 기간·방법·서류 |
| 하단 고정 버튼 | `원문 보러가기` → 도/시 공식 페이지 새 창 |
| 면책 | "신청은 공식 사이트에서 진행됩니다. 최신 정보는 원문을 확인해 주세요." |

**중요:** 신청을 우리가 받지 않는다. 폼도 만들지 않는다. 안내하고 공식 채널로 보낸다.

---

### S3. 3초 온보딩 (오버레이)

첫 방문 시 자동으로 뜨는 오버레이. 별도 페이지가 아니다.

| 영역 | 보이는 것 |
|---|---|
| 문항 1 | **나이** — 숫자 입력 또는 `19-24` `25-29` `30-34` 버튼 |
| 문항 2 | **진주에 살아?** — `네` / `아니요` |
| 문항 3 | **지금 뭐 해?** — `대학생` / `직장인` / `구직중` |
| 하단 | `건너뛰기` (항상 노출) · `완료` |

- 건너뛰어도 전체 목록은 그냥 보인다. **막는 화면이 아니다.**
- 완료하면 오버레이가 닫히고 홈에 필터가 적용된다.
- 한 번 완료/건너뛰면 다시 뜨지 않는다. 헤더의 `조건 바꾸기`로만 다시 연다.

## 2. 기능 목록

사용자가 할 수 있는 행동 8가지.

| # | 기능 | 동작 | 완료 판정 |
|---|---|---|---|
| F1 | 피드 훑어보기 | 홈에서 아래로 스크롤하며 카드를 본다 | 로그인·검색·입력 **없이** 첫 화면에서 바로 정책이 보인다 |
| F2 | 분야로 거르기 | 필터칩을 눌러 해당 분야만 본다 | 칩을 누르면 즉시 목록이 바뀐다. 다시 누르면 해제 |
| F3 | 상세 보기 | 카드를 눌러 상세로 이동 | 4블록이 모두 채워져 보인다 |
| F4 | 원문으로 이동 | 상세 하단 버튼으로 공식 사이트 이동 | 새 창으로 열리고, **링크가 실제로 살아 있다** |
| F5 | 내 조건 입력 | 온보딩 3문항에 답한다 | 답이 브라우저에 저장되고 홈에 반영된다 |
| F6 | 조건 건너뛰기 | 온보딩을 건너뛴다 | 전체 목록이 그대로 보인다. 다시 묻지 않는다 |
| F7 | 조건 바꾸기 | 헤더 버튼으로 온보딩을 다시 연다 | 이전 답이 채워진 상태로 열린다 |
| F8 | 뒤로 가기 | 상세 → 홈 복귀 | **직전 필터와 스크롤 위치가 유지된다** |

**시스템이 자동으로 하는 것 (사용자 행동 아님):**

- 마감 임박순 정렬
- 마감일이 지난 정책 숨김
- 내 조건에 맞는 정책만 남기기 (F5를 한 경우)
- 오늘 날짜 기준 D-day 계산

> ⚠️ F8의 "필터·스크롤 유지"는 빼먹기 쉬운데, 이게 없으면 상세를 한 번 볼 때마다 맨 위로 튕겨서 **피드로서 못 쓰게 된다.** 반드시 넣을 것.

## 3. 데이터

저장소는 두 곳뿐이다. **DB는 없다.**

### 3-1. 정책 데이터 — `data/policies.json` (손으로 작성)

| 필드 | 타입 | 필수 | 예시 | 설명 |
|---|---|:---:|---|---|
| `id` | string | ✅ | `"jj-001"` | 고유 ID. 상세 페이지 주소가 된다 |
| `title` | string | ✅ | `"진주시 청년 자격증 응시료 지원"` | 공식 정책명 |
| `summary` | string | ✅ | `"진주 살면 자격증 시험비 돌려줌"` | **한 줄 요약. 이 서비스의 심장. 30자 내외** |
| `category` | enum | ✅ | `"교육"` | `일자리` `주거` `교육` `복지문화` `금융` 중 하나 |
| `source` | enum | ✅ | `"진주시"` | `경남도` / `진주시` |
| `benefitLabel` | string | ✅ | `"최대 30만원"` | 카드에 크게 뜨는 혜택 크기. 금액 없으면 `"무료"` 등 |
| `applyStart` | date \| null | ✅ | `"2026-08-01"` | 신청 시작일. 상시모집이면 `null` |
| `applyEnd` | date \| null | ✅ | `"2026-08-31"` | 신청 마감일. **`null`이면 상시모집** |
| `minAge` | number | ✅ | `19` | 대상 최소 나이 |
| `maxAge` | number | ✅ | `34` | 대상 최대 나이 |
| `requiresJinju` | boolean | ✅ | `true` | 진주 거주가 조건인지. 도 정책은 보통 `false` |
| `targetStatus` | string[] | ✅ | `["대학생","구직중"]` | 대상 신분. **빈 배열 `[]` = 전원 해당** |
| `who` | string | ✅ | `"만 19~34세 진주시 거주 청년"` | 상세 블록 1 본문 |
| `howMuch` | string | ✅ | `"1인당 연 30만원 한도, 실비 지원"` | 상세 블록 2 본문 |
| `howTo` | string | ✅ | `"진주시 청년온라인플랫폼에서 신청"` | 상세 블록 3 본문 |
| `sourceUrl` | string | ✅ | `"https://young.jinju.go.kr/..."` | 원문 링크. **깨지면 안 됨** |

**파일 최상단에 함께 둘 것:**

| 필드 | 예시 | 설명 |
|---|---|---|
| `updatedAt` | `"2026-08-06"` | 푸터의 `O년 O월 O일 기준` 표기에 사용 |

### 3-2. 브라우저 저장 — localStorage

| 키 | 타입 | 예시 | 설명 |
|---|---|---|---|
| `jinjuyouth.onboarded` | boolean | `true` | 온보딩을 봤는지. 건너뛰어도 `true` |
| `jinjuyouth.age` | number \| null | `24` | 나이. 건너뛰면 `null` |
| `jinjuyouth.inJinju` | boolean \| null | `true` | 진주 거주 여부 |
| `jinjuyouth.status` | enum \| null | `"대학생"` | `대학생` / `직장인` / `구직중` |

### 3-3. 저장하지 않고 계산하는 값

| 값 | 계산 방법 |
|---|---|
| D-day | `applyEnd` − 오늘. `applyEnd`가 `null`이면 `상시` |
| 마감 여부 | D-day < 0 이면 목록에서 제외 |
| 내 조건 일치 | 나이가 `minAge`~`maxAge` 안 **AND** (`requiresJinju`가 `false` 또는 내가 진주 거주) **AND** (`targetStatus`가 비었거나 내 신분 포함) |

## 4. 이번에 만들지 않을 것

명세만큼 중요한 목록이다. **여기 있는 걸 만들기 시작하면 프로토타입이 끝나지 않는다.**

| 안 만드는 것 | 이유 |
|---|---|
| 로그인 · 회원가입 · 본인인증 | **없는 게 이 서비스의 차별점이다.** 경남 도 플랫폼이 이걸 요구해서 사람들이 이탈한다 |
| 관리자 페이지 | 데이터는 JSON 파일을 직접 고친다. 30건짜리에 CMS는 과하다 |
| 데이터베이스 · 백엔드 서버 | 정적 JSON으로 충분. 서버가 생기면 배포·비용·장애가 따라온다 |
| **공공데이터 API 연동 · 크롤링 · 자동 갱신** | 프로토타입이라 불필요. 실서비스 전환 시 이 부분만 교체 |
| 신청서 접수 · 결제 | 신청은 공식 사이트에서. 우리는 안내만 한다 |
| 알림 (푸시 · 카톡 · 이메일) | 발송에 사업자 등록·인증이 필요. **마감 D-day 뱃지가 그 역할을 대신한다** |
| 검색창 | 30건 규모에서 검색은 필요 없다. 필터칩으로 충분하고, 검색창은 "찾아야 하는 사이트" 인상을 준다 |
| 진주 외 17개 시군 | 범위 확대는 실패 지름길. 발표에서 "확장 계획"으로만 언급 |
| 댓글 · 후기 · 커뮤니티 | 사용자가 없으면 빈 게시판만 남는다 |
| 통계 · 조회수 · 대시보드 | 보여줄 데이터가 없다 |
| 다국어 · 다크모드 | 심사에 영향 없음 |
| 네이티브 앱 | 웹으로만. 링크 하나로 제출한다 |

### ⬜ 아직 결정 안 된 것 — 일단 만들지 않음으로 둠

기획안에서 네가 정하기로 남겨둔 항목이다. **현재 명세에는 빠져 있다.**

| 항목 | 넣는다면 필요한 것 |
|---|---|
| **북마크 (공고 저장)** | 카드에 하트 아이콘 + localStorage에 `savedIds` 배열 + 저장 목록 화면 1개 추가 |
| **내 일정 (캘린더)** | 화면 1개 추가. 북마크가 먼저 있어야 의미가 있다 |

→ 둘 다 슥삭에는 있는 기능. 넣으려면 **북마크만** 먼저 넣는 걸 권한다 (화면 추가 없이 카드에 아이콘 하나로 끝나고, "관심 있는 걸 담아둔다"는 행동은 피드와 잘 맞는다). 캘린더는 프로토타입 범위를 넘는다.
