# 진주청년 — 서비스 기획안

---

## 1. 서비스 이름

### 진주청년

경남도 정책까지 함께 다루지만, 이름은 **진주**에 건다. "경남 청년정책 통합 플랫폼" 같은 이름은 이미 있는 관공서 플랫폼과 구별되지 않고, 첫 사용자가 진주 청년이기 때문.

> ⚠️ 참고: 진주시 공식 채널은 "진주시 청년온라인플랫폼"이라 이름이 겹치지 않음. 다만 [진주청년회의소(JCI)](https://www.facebook.com/jinjujci/)라는 별개 단체가 있어 검색 시 섞일 수 있음.

---

## 2. 문제 정의

경남 청년들이 자기가 받을 수 있는 지원을 못 받는다.
**정보가 없어서가 아니라, 19개 사이트에 흩어져 있고 들어가는 게 번거로워서다.**

실제 사이트를 확인한 결과:

- **[경상남도 청년정보플랫폼](https://youth.gyeongnam.go.kr/)은 "통합 플랫폼"을 표방하지만 실제로는 링크 모음이다.** 하단에 시군별 청년플랫폼 링크 18개를 나열해뒀을 뿐, 창원·진주·김해·양산 정책을 보려면 각각 다시 들어가야 한다.
- **작정하고 찾아야만 정보에 닿는다.** 회원가입·로그인 기반이고, "청년맞춤검색" 폼을 채워야 결과가 나온다.
- **목록만 봐서는 나한테 해당되는지 알 수 없다.** [진주시청년온라인플랫폼](https://young.jinju.go.kr/)의 경남청년정책 48건은 카드에 분야·정책명·신청기간만 있고, 대상 연령과 지원내용은 하나하나 눌러봐야 나온다.
- **문체가 관공서 문체다.** "만 19~34세 도내 거주 미취업 청년 대상 자산형성 지원" — 읽다가 그만두게 된다.

결론: 정보 부족 문제가 아니라 **도달 실패 문제**다.

## 3. 타겟 사용자

**1차 타겟 — 진주시에 사는 만 19~34세 청년**

- 청년정책이 있다는 건 알지만, 어디서 뭘 볼지 몰라 안 찾아본 사람
- 로그인·본인인증 단계에서 이탈해본 경험이 있는 사람
- "작정하고 검색"할 만큼 급하진 않지만, **눈앞에 보이면 신청할** 사람

**핵심 사용 맥락:** 작정하고 찾을 때가 아니라 **시간 남을 때 가볍게 둘러보는 순간.**
→ 그래서 이 서비스는 "검색 사이트"가 아니라 **"피드"** 여야 한다.

**첫 버전 대상 범위:** 경상남도 + 진주시 (18개 시군 전체는 하지 않음)

## 4. 핵심 기능 3개

### ① 도 + 시 정책을 한 목록에 합친 피드
경남도 정책과 진주시 정책이 출처 뱃지(`경남도` / `진주시`)만 달고 **한 줄로 섞여 흐른다.** 사이트를 옮겨 다닐 필요가 없다. 표·게시판이 아니라 세로로 흐르는 카드 형태.

### ② 한 줄 요약 — 관공서 문체를 사람 말로 번역
이 서비스의 심장.

> 원문: "만 19~34세 도내 거주 미취업 청년 대상 자산형성 지원"
> 우리: **"진주 살고 34살 이하면 매달 저금할 때 시가 얹어줌"**

혜택 크기(`월 20만원`, `최대 300만원`, `무료`)를 카드에서 바로 크게 보여준다.

### ③ 마감 D-day 뱃지 + 임박순 정렬
`D-12` 뱃지를 달고 **급한 것이 위로** 온다. 상시모집은 회색 `상시` 뱃지로 아래에 배치. 마감 지난 건 목록에서 내린다.

> 📌 **4번째 후보였다가 뺀 것:** *3초 온보딩* (나이/거주지/신분 3문항 → 해당되는 것만 필터, 로그인 없이 브라우저에 저장).
> "번거로움 제거"를 가장 직접적으로 보여주는 기능이라 셋 중 하나와 바꿀 만함. 무엇을 뺄지는 네가 결정할 것.

## 5. 화면 구성

### 화면 1 — 홈 (카드 피드) · 메인
- 상단: 필터칩 `전체` `일자리` `주거` `교육` `복지·문화` `금융`
- 본문: 세로로 흐르는 카드. 카드 1장에 들어가는 것 —
  - `D-12` 마감 뱃지
  - 분야 컬러칩
  - 정책 이름
  - **한 줄 요약**
  - 혜택 금액 강조
  - `경남도` / `진주시` 출처 뱃지
- 기본 정렬: 마감 임박순
- 하단: `2026년 O월 O일 기준` 갱신 날짜 표기 (필수)

### 화면 2 — 상세
- 4블록 구성: **한 줄 요약 → 누가 받나 → 얼마 받나 → 어떻게 신청하나**
- 맨 아래 `원문 보러가기` 버튼 → 도/시 공식 페이지로 이동
- 신청은 우리가 받지 않는다. 안내만 하고 공식 채널로 보낸다.

### 화면 3 — 3초 온보딩 (선택, 건너뛰기 가능)
- 첫 방문 시 3문항: **나이 / 진주 거주 여부 / 신분(대학생·직장인·구직중)**
- 답하면 해당 정책만 필터. 안 해도 전체 목록은 그냥 보인다.
- 로그인 없음. 브라우저에만 저장.

## 6. 참고한 사례

### 조사 완료 — 기존 서비스 현황 (경쟁/현황)

| 서비스 | 성격 | 확인한 점 |
|---|---|---|
| [경상남도 청년정보플랫폼](https://youth.gyeongnam.go.kr/) | 도 단위 공식 | "통합"이지만 시군은 링크 18개 나열. 로그인 필요. 알림신청 기능 있음 |
| [진주시청년온라인플랫폼](https://young.jinju.go.kr/) | 시 단위 공식 | 경남청년정책 48건, 12개씩 4페이지. 목록엔 연령·지원내용 없음 |
| [온통청년](https://www.youthcenter.go.kr/) | 국가 단위 통합 | 전국 청년정책 통합 포털. 전국 청년플랫폼 목록 제공 |
| [공공데이터포털 – 청년정책 API](https://www.data.go.kr/data/15143273/openapi.do) | 데이터 소스 | 무료·개발단계 자동승인. 법정시군구코드로 지역 필터 가능 |

### 벤치마킹 사례 — [슥삭 (ssgsag.kr)](https://www.ssgsag.kr/)

대학생 대상 대외활동·공모전·인턴 정보 플랫폼. 운영사는 (주)이십사점오. 웹 + iOS/안드로이드 앱.
**진주청년이 지향하는 형태가 이것이다.** 다루는 정보만 "공모전 → 청년정책"으로, 범위만 "전국 대학생 → 진주 청년"으로 바꾼 구조.

**따올 것:**

| 슥삭의 방식 | 진주청년에 적용 |
|---|---|
| 카테고리 4분류 (대외활동/공모전/인턴십/교육·강연) | 분야 5분류 (일자리/주거/교육/복지·문화/금융) — 더 늘리지 않는다 |
| "추천 공고" — 개인화 맞춤 추천 | 3초 온보딩(나이·거주지·신분) 기반 필터 |
| **마감 알림 설정** | 마감 D-day 뱃지 + 임박순 정렬 |
| 친근·캐주얼한 말투 (`슥삭이 콕 집은 공고`, `요즘 핫한 공고`) | **한 줄 요약의 문체 기준.** 관공서 문체를 이 톤으로 번역한다 |

→ 이로써 **화면 톤이 확정됐다: 토스처럼 깔끔한 쪽이 아니라 친근·캐주얼한 쪽.**

> ⚠️ 확인 못 한 것: 슥삭의 카드 디자인 세부(썸네일 유무, 마감일 표기 형식)는 사이트 HTML에서 확인되지 않았음. **앱을 직접 깔아서 카드 한 장을 캡처해두는 것을 권함** — 우리 카드 디자인의 출발점이 된다.

> 📌 **슥삭에 있는데 우리 기능 3개엔 없는 것:** `공고 저장(북마크)` / `내 일정(캘린더)`.
> 임의로 추가하지 않고 남겨둠. 넣을지 말지는 네가 결정할 것.

## 부록 — 함께 정해진 실행 조건

- **목적:** 수업 과제·공모전 제출용 (동작하는 데모 + 기획 스토리)
- **데이터 수집:** 크롤링하지 않음. 공공데이터 API로 받아 `data/policies.json` 스냅샷 저장 → 한 줄 요약은 사람이 직접 작성 (50~150건 규모라 가능)
- **기술 구성:** Next.js + Tailwind CSS + 정적 JSON + Vercel 무료 배포. **DB·서버·로그인 없음**
- **가장 큰 리스크:** 심사에서 나올 *"경남 청년정보플랫폼 이미 있는데요?"* → 답은 **로그인 없음 + 한 줄 요약 + 마감 D-day**
