# 기획서 — 잇다

## 서비스 이름
잇다

## 문제 정의
진주시 청년들은 부족한 청년 커뮤니티 때문에 미래 대비를 못한다.

- 정보 공유 커뮤니티의 부재: 진주시청년온라인플랫폼은 주거·일자리·복지 정책이 한 곳에 몰려있어 구분하기 어렵고, 청년끼리 경험을 나누는 소통 공간은 따로 없다.
- 안정적인 정주환경의 부재: 물리적인 청년 커뮤니티 공간이 있다는 사실 자체를 알기 어려워, 청년들이 진주에 계속 머물고 싶게 만드는 연결이 만들어지지 않는다.

## 타겟 사용자
진주 거주, 19세 ~ 34세 청년

## 핵심 기능 (2026-08-06 4개로 확장, 2026-08-07 참여 추가로 5개)
1. **관심사 기반 피드**: 정책 카드와 오프라인 공간 카드가 섞인 정보탭 피드. 주거/일자리/문화/커뮤니티 태그로 필터링해서, 목적 없이 훑어보다가 정보와 공간을 동시에 만나는 경험을 제공한다. 우측 상단 검색창으로 "청년", "월세" 같은 키워드 검색도 가능하다.
2. **정책 정보 큐레이션**: 정책 카드를 누르면 상세 설명과 신청 바로가기 링크를 보여준다. 3초 온보딩(나이대·거주·신분)에 따른 추천, 마감 D-day 뱃지(7일 이하는 빨간 네모)를 더한다. (2026-08-06 온보딩으로 보강)
3. **오프라인 공간 지도 연결**: 모의 지도 기반으로 청년 커뮤니티 공간의 위치를 보여주고, 소개·사진·후기를 함께 제공한다.
4. **찜(마이) 기능**: 관심 있는 정책·공간을 하트 버튼으로 찜해두고, 마이탭에서 모아보고 내 정보 기반 추천도 받는다. (2026-08-06 추가)
5. **참여(활동 모집)**: 청년이 직접 활동 모집 글을 올리고 서로 참여를 신청한다. 기획서가 정의한 "청년끼리 경험을 나누는 소통 공간의 부재"에 직접 답하는 기능이다. 정책·공간은 시가 주는 정보지만, 참여는 청년이 만드는 내용이다. (2026-08-07 문서화 — 구현은 앞서 완료됨)

## 화면 구성 (탭 구조)
탭 버튼은 화면 하단에 크게 배치한다 (슥삭처럼 모바일에서 누르기 쉬운 크기). (2026-08-06 변경)

1. **정보탭** (`/`) — 정책 카드 + 공간 카드 목록, 관심사 필터, 3초 온보딩 기반 신분 추천, 검색, 모의 로그인
   (탭 순서는 정보 → 공간 → 참여 → 마이)
2. 정책 상세 화면 — 정책 설명, 6하원칙, 신청 바로가기 링크, 찜 버튼
3. 공간 상세 화면 — 지도 위치, 6하원칙, 사진, 공간 소개, 후기, 찜 버튼
4. **공간탭** (`/places`) — 모의 지도에서 공간(기관)을 검색하고 찾기
5. **참여탭** (`/join`, 2026-08-07 문서화) — 활동 모집 글 목록, 글쓰기(`/join/new`), 글 상세·참여(`/join/[id]`)
6. **마이탭** (`/my`, 2026-08-06 추가) — 모의 로그인 사용자 정보, 내 조건, 추천 정책 4개, 찜한 목록

> 지도는 실제 카카오맵 API 연동 대신, 상대 좌표로 위치를 표시하는 모의 지도로 구현한다. (2026-08-06 변경 — 외부 API 키 의존 없이 프로토타입을 완성하기 위함)
> 탭 이름: 기존 "홈"/"장소"를 "정보"/"공간"으로 변경. (2026-08-06 변경)
> 목업 데이터 분량: 정책 16건, 공간 14건으로 확대. (2026-08-06 변경)
> 사진 영역: 카드 목록에는 정책·공간 모두 썸네일 표시. **상세 화면 사진은 공간에만** 남기고 정책 상세에서는 제외. (2026-08-06 변경)
> 상세 화면 정보량: 정책·공간 상세 모두 6하원칙(누가/언제/어디서/무엇을/어떻게/왜) 구조로 확장. (2026-08-06 변경)
> 지도 배경: 모의 지도의 회색 격자 배경을 실제 진주 지역 지도 이미지로 교체 (점의 위치는 실제 GPS와 정확히 일치하지 않는 장식적 배경). (2026-08-06 변경)
> 공간 상세 레이아웃: 지도를 사진보다 위로 이동 (지도 → 6하원칙 → 사진 → 후기 순). (2026-08-06 변경)
> D-day 뱃지: 홈 화면(정보탭)에서는 정책·공간 카드 모두에 표시. 공간은 임의 날짜라 의미는 없음. `/공간탭` 목록에는 적용하지 않음. (2026-08-06 변경)
> 온보딩: 나이대·거주·신분 3문항 오버레이로 필터링을 강화. 기존 "나는 지금 [대학생/직장인]" 칩은 제거하고 온보딩으로 대체. 신분은 대학생/직장인/**구직중** 3종으로 확대. (2026-08-06 추가)
> 로그인: 실제 인증이 아닌 **모의 로그인** (버튼 클릭 시 랜덤 닉네임 배정, localStorage에만 저장). 서버·DB·Supabase는 쓰지 않음. (2026-08-06 추가)
> 찜: 정책·공간 카드/상세 전체에 하트 버튼을 추가하고 localStorage에 저장. **로그인해야 찜할 수 있고**, 로그인 안 한 상태에서 누르면 마이탭(로그인 화면 역할)으로 이동한다. (2026-08-06 추가, 2026-08-06 로그인 필요로 변경)
> 참여: 글 작성·참여·삭제 모두 **로그인이 필요**하고 localStorage에만 저장한다. 글쓴이는 자기 글에 참여/취소할 수 없다(작성 시 자동으로 참여자에 포함). 정원이 차면 `마감`으로 잠긴다. 삭제는 글쓴이만 가능하고 확인창을 띄운다. (2026-08-07 문서화)

## 화면 톤 (2026-08-07 추가)

**진주시 공식 캐릭터 하모의 색 라인을 따른다.** 하모는 진양호·남강에 사는 수달을 모티브로, 머리에 진주조개를 얹고 왕진주 목걸이를 하고 꼬리에 물결무늬가 있다. 이름은 "동의·긍정"을 뜻하는 진주 방언이다. 진주에 사는 청년이 매일 보는 얼굴의 색을 쓰면, 이 서비스가 어느 도시 것인지 설명 없이 읽힌다.

기준값은 **`#b0cffc`** 다. 다만 이 색은 밝기가 84%여서 흰 배경 대비가 1.4:1밖에 안 되고, 글자색이나 버튼색으로는 읽히지 않는다. 그래서 같은 색상각(216°)에서 위아래로 계단을 만들어 역할을 나눈다 — 배경은 더 밝게, 버튼과 글자는 더 어둡게. 회색도 무채색 대신 같은 216° 계열을 써서 화면 전체가 한 가족으로 읽히게 한다. 구체적인 값은 `requirements.md`의 "화면 톤·디자인 규칙" 절에 있다.

> **캐릭터 이미지는 쓰지 않는다.** 색만 참고한다. 하모 일러스트를 화면에 넣으려면 진주시에 사용신청을 해야 하므로, 이 프로토타입 범위 밖이다. 대신 하모의 왕진주 목걸이에서 따온 **작은 진주 알**을 강조 표시로 쓴다 (하단탭 활성 표시, 섹션 제목 앞, 지도의 강조된 공간 — 이 세 곳만).

## 참고한 사례
- **슥삭**: 기존 대외활동 공유 서비스가 있어도, 정보를 가볍게 넘겨 보는 사용자 경험으로 차별화한 사례
- **부산청년플랫폼**: 취업 정보뿐 아니라 일자리·주거·문화·교육 정보를 통합 제공
- **청바지**: 회원가입 시 관심분야를 선택해 개인 맞춤형 정책을 추천하고, 챗봇으로 정책을 카드 형태로 안내
- **청년두드림센터(부산진구), 부산청년센터(부산중구), 바른청년연합센터**: 오프라인 공간 방문조사 — 목적 없이 방문했다가 정보와 사람을 자연스럽게 만나는 연결 방식을 참고
- **진주시청년온라인플랫폼**: 정책과 커뮤니티 정보가 뒤섞여 있고 유저 친화성이 낮은 기존 서비스의 한계를 비교 대상으로 참고
