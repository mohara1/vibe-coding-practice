# 요구사항 명세 — 잇다

## 0. 탭 내비게이션 (2026-08-06 변경, 2026-08-07 참여 추가)
- 탭 버튼은 화면 **하단**에 고정 (기존 상단 → 하단)
- 탭 순서: **정보**(기존 "홈") / **공간**(기존 "장소") / **참여** / **마이**
- 모바일에서 누르기 쉽도록 버튼 크기를 키움 (슥삭 스타일 참고) — 탭 하나의 터치 영역은 최소 44px 높이
- 활성 탭은 하모 색 아이콘 + 아이콘 아래 **진주 알** 하나로 표시한다
- 아이폰 홈 인디케이터에 가리지 않도록 하단에 `env(safe-area-inset-bottom)` 만큼 여백을 둔다

## 1. 화면 목록

### 정보탭 (`/`)
- 우측 상단: **로그인 버튼**, 그 아래 **검색창** — "청년", "월세" 같은 키워드로 제목·요약·설명을 검색 (2026-08-06 추가)
- **3초 온보딩 오버레이** (첫 방문 시 자동 표시, 2026-08-06 추가) — 아래 "온보딩 오버레이" 참고. 완료하면 `24살 · 진주 거주 · 대학생 기준으로 보는 중` 형태의 **내 조건 배너**가 검색창 아래에 나타나고, 배너의 `조건 바꾸기`로 다시 열 수 있음
  - 기존에 있던 "나는 지금 [대학생/직장인]" 칩은 온보딩으로 대체되어 제거됨
- 정책 카드와 공간 카드가 섞인 목록
- 관심사 태그 필터 (주거 / 일자리 / 문화 / 커뮤니티)
- 온보딩에서 신분을 선택했다면, 정책 카드 중 해당 신분에 추천되는 것만 보임. 공간 카드는 영향받지 않음
- 카드에는 사진(또는 플레이스홀더), **찜(하트) 버튼**, 제목, 카테고리 태그, 한 줄 요약이 보임. **정책·공간 카드 모두 제목 옆에 D-day 뱃지**를 보여줌 — 공간은 실제 마감 개념이 없어 임의의 날짜로 표시 (의미 없는 장식용). `/공간탭` 목록 카드에는 D-day를 적용하지 않음
  - **찜 버튼은 로그인이 필요함** (2026-08-06 변경) — 로그인 안 한 상태로 누르면 찜되지 않고 마이탭(로그인 화면 역할)으로 이동함
- 검색/필터 결과가 0건이면 "검색 결과가 없어요" 안내 표시
- 카드를 누르면 종류에 따라 정책 상세 또는 공간 상세로 이동

### 3초 온보딩 오버레이 (2026-08-06 추가)
- 첫 방문 시 자동으로 뜨는 오버레이 (별도 페이지 아님)
- 문항: **나이대**(19-24 / 25-29 / 30-34) · **진주에 살아요?**(네 / 아니요) · **지금 뭐 해요?**(대학생 / 직장인 / 구직중)
- 하단 버튼: `건너뛰기`(항상 노출) · `완료`
- 건너뛰어도 전체 목록은 그대로 보임 — 막는 화면 아님
- 완료/건너뛰기 하면 localStorage에 저장되어 다시 뜨지 않음. 정보탭의 `조건 바꾸기` 또는 마이탭의 `조건 바꾸기`로만 다시 열림
- "진주에 살아요?" 응답은 저장은 하지만, 현재 데이터가 전부 진주시 정책이라 실제 필터링에는 반영하지 않음 (나이대·신분만 추천 로직에 사용)

### 정책 상세 화면 (2026-08-06 대폭 개편)
- 카테고리 태그 옆 **찜(하트) 버튼** (2026-08-06 추가)
- 정책 제목 옆 **마감 D-day 뱃지**
- 카테고리 태그, 한 줄 요약
- **6하원칙 블록** — 누가(대상) / 언제(신청·사업 기간) / 어디서(신청 장소·주관 기관) / 무엇을(지원 내용) / 어떻게(신청 방법) / 왜(정책 목적)
- 신청 바로가기 링크(버튼)
- 정보탭으로 돌아가는 버튼
- 사진 영역 없음 — 정책 상세에서는 사진을 보여주지 않음 (2026-08-06 변경: 카드 목록의 썸네일과 공간 상세의 사진은 유지, 정책 상세만 제외)

### 공간 상세 화면 (2026-08-06 대폭 개편)
- 모의 지도 위치 표시 (해당 공간 위치를 강조, 실제 지도 이미지 배경 위에 표시) — 사진보다 **위쪽**에 배치 (2026-08-06 위치 변경)
- 카테고리 태그 옆 **찜(하트) 버튼** (2026-08-06 추가)
- 공간 이름, 카테고리 태그
- **6하원칙 블록** — 누가(주요 이용자) / 언제(운영시간) / 어디서(위치) / 무엇을(제공하는 것) / 어떻게(이용 방법) / 왜(방문 이유)
- **사진** (실제 사진이 없으면 카테고리 아이콘 플레이스홀더로 대체) — 6하원칙 블록과 후기 사이에 배치 (2026-08-06 위치 변경)
- 후기 목록 (작성자, 내용)
- 정보탭으로 돌아가는 버튼

### 공간탭 (`/places`) (기존 "장소 탭"에서 이름 변경, 2026-08-06)
- 검색창 — 기관 이름으로 검색
- 관심사 태그 필터 (주거 / 일자리 / 문화 / 커뮤니티)
- 모의 지도 — **진주 지역 실제 지도 이미지를 배경으로 깔고**, 그 위에 필터링된 공간(기관) 점을 표시. 각 위치를 누르면 공간 상세로 이동 (2026-08-06 변경)
  - 참고: 지도 이미지는 배경 그림일 뿐, 점의 위치는 실제 GPS 좌표와 정확히 일치하지 않는 모의 배치임
- 지도 아래 목록 — 필터링된 공간을 사진과 함께 **찜 버튼**을 포함한 리스트로도 보여줌 (지도가 익숙하지 않은 사용자를 위한 대안, 2026-08-06 찜 버튼 추가) — 이 목록의 카드에는 D-day를 표시하지 않음

### 참여탭 (`/join`) (2026-08-07 문서화 — 구현은 앞서 완료됨)
- 제목 `참여` + 우측 `작성하기` 버튼
- `작성하기`는 **로그인이 필요함** — 로그인 안 한 상태로 누르면 마이탭(로그인 화면 역할)으로 이동
- 등록된 활동 모집 글을 카드 목록으로 보여줌 (2열, 모바일에서는 1열)
- 카드에는 제목, 글쓴이 닉네임, 참여 인원 `n/총원`이 보임
- 글이 하나도 없으면 "아직 등록된 활동이 없어요" 안내 표시
- 카드를 누르면 글 상세로 이동

### 모집 글쓰기 (`/join/new`) (2026-08-07 문서화)
- 로그인하지 않고 접근하면 마이탭으로 즉시 되돌림
- 입력: **제목**(한 줄) · **내용**(여러 줄) · **총 참여 인원**(숫자, 2 이상)
- 총 참여 인원이 2 미만이면 "2명 이상으로 설정해주세요" 안내를 보여주고 `게시하기`를 잠금
- 제목·내용이 비어 있으면 `게시하기` 잠금
- 하단 버튼 2개: `취소`(확인창 후 참여탭으로) · `게시하기`(등록 후 방금 쓴 글 상세로 이동)
- 글을 쓰면 **글쓴이가 참여자 1번으로 자동 포함**됨

### 모집 글 상세 (`/join/[id]`) (2026-08-07 문서화)
- 참여탭으로 돌아가는 버튼
- 제목, 글쓴이 닉네임, 내용(줄바꿈 유지), `참여 인원 n/총원`
- 상태별 버튼 (하나만 보임)
  - 아직 참여 안 함 + 자리 있음 → `참여하기`. 로그인 안 했으면 누를 때 마이탭으로 이동
  - 이미 참여함 → "이미 참여한 활동입니다" + `참여 취소하기`. **단 글쓴이는 취소 버튼이 없음** (자기 활동에서 빠질 수 없음)
  - 정원이 찼고 참여 안 함 → `마감` (누를 수 없음)
- **글쓴이에게만** 아래쪽에 `삭제하기`가 보임 — 누르면 "이 글을 삭제할까요? 삭제하면 되돌릴 수 없어요." 확인창을 띄우고, 지우면 참여탭으로 이동
- 없는 id로 들어오면 "게시글을 찾을 수 없어요" 안내 (localStorage에만 저장되므로 다른 브라우저에서는 글이 보이지 않음)

### 마이탭 (`/my`) (2026-08-06 신규)
- 로그인 안 했을 때: "로그인하면 내 정보와 찜한 목록을 볼 수 있어요" 안내 + 로그인 버튼만 표시
- 로그인 했을 때:
  1. **모의 사용자 이름** — 실제 계정이 아니라 로그인 시 랜덤으로 배정되는 닉네임 (예: "진주달빛청년")
  2. **내 정보** — 온보딩으로 얻은 나이대·거주·신분 요약 + `조건 바꾸기` 버튼 (누르면 정보탭 온보딩 오버레이가 다시 열림)
  3. **추천 정책 4개** — 내 신분에 맞는 정책 중 4개 (신분 미설정 시 상위 4개로 대체)
  4. **찜한 목록** — 찜한 정책·공간을 모두 카드로 보여줌. 없으면 "아직 찜한 게 없어요" 안내
  5. **내가 쓴 글** — 내가 올린 활동 모집 글을 카드로 보여줌. 없으면 "아직 작성한 모집 글이 없어요" 안내 (2026-08-07 문서화)

## 2. 기능 목록 (사용자가 할 수 있는 행동)

- 정보탭에서 정책/공간 카드 목록 보기
- 우측 상단 검색창에 키워드를 입력해 카드 검색하기
- 관심사 태그를 눌러 카드 목록 필터링하기
- **3초 온보딩에 답하거나 건너뛰기** (2026-08-06 추가) — 답하면 나이대·거주·신분이 저장되고 정책 추천에 반영됨
- **내 조건 배너의 `조건 바꾸기`로 온보딩 다시 열기** (2026-08-06 추가)
- **검색창 옆 로그인 버튼으로 모의 로그인/로그아웃하기** (2026-08-06 추가)
- **카드·상세 화면의 하트 버튼으로 정책·공간을 찜하거나 찜 해제하기** (2026-08-06 추가). 로그인 안 한 상태면 하트를 눌렀을 때 찜 대신 마이탭으로 이동함 (2026-08-06 변경)
- 정책 카드를 눌러 정책 상세 화면으로 이동하기
- 공간 카드를 눌러 공간 상세 화면으로 이동하기
- 정책 상세에서 신청 바로가기 링크를 눌러 외부 페이지로 이동하기
- 공간 상세에서 지도로 위치 확인하기
- 공간 상세에서 사진과 등록된 후기 보기
- 상세 화면에서 정보탭으로 돌아가기
- 하단 탭으로 정보/공간/**마이** 화면 사이를 이동하기 (2026-08-06 마이 추가)
- 공간탭에서 기관 이름으로 검색하기
- 공간탭에서 관심사 태그로 지도 위 표시를 필터링하기
- 공간탭 지도에서 위치를 눌러 공간 상세로 이동하기
- **마이탭에서 로그인 후 내 정보·추천 정책 4개·찜한 목록·내가 쓴 글 보기** (2026-08-06 추가, 2026-08-07 내가 쓴 글 문서화)
- **참여탭에서 활동 모집 글 목록 보기** (2026-08-07 문서화)
- **활동 모집 글 쓰기** — 제목·내용·총 참여 인원을 입력해 등록 (로그인 필요)
- **모집 글에 참여하거나 참여 취소하기** (로그인 필요, 글쓴이는 자기 글에서 취소 못 함)
- **내가 쓴 모집 글 삭제하기** (확인창을 거침)

**D-day 뱃지 규칙 (계산값, 저장하지 않음):**
- `applyEnd`가 null → 회색 네모 `상시`
- 마감일이 지났으면 → 회색 네모 `마감`
- 오늘부터 마감일까지 남은 일수가 **7일 이하** → 빨간 네모 `D-3` 등
- 8일 이상 남았으면 → 회색 네모 `D-14` 등

## 4. 화면 톤·디자인 규칙 (2026-08-07 추가)

색·글꼴·간격을 찾을 때는 **이 절만 본다.** 여기 적힌 hex 값은 `src/app/globals.css`의 `@theme` 선언과 글자 단위로 같아야 한다. 색을 바꾸려면 이 표를 먼저 고친다.

기준값은 진주시 캐릭터 하모의 `#b0cffc` 다 (이유는 `plan.md`의 "화면 톤" 절). 이 색 자체는 너무 밝아 글자·버튼에 못 쓰므로, 같은 색상각 216°에서 계단을 만들어 역할을 나눈다.

### 4.2 중립색

무채색(`zinc`) 대신 **`slate`** 를 쓴다. `slate`는 색상각이 216°대라 하모와 같은 가족이고, 회색조차 살짝 하모 쪽으로 기울어 화면이 한 덩어리로 읽힌다.

배경 `hamo-50` · 면 `white` · 테두리 `slate-200` · 본문 `slate-600` · 보조 글자 `slate-500` · 흐린 글자 `slate-400` · 제목 `hamo-900`

### 4.3 카테고리 4색

네 색 모두 **바탕은 밝기 ~92%, 글자는 ~35%** 로 같은 층에 놓아 한 시스템으로 읽히게 한다. 색상각은 216 → 187 → 262 → 342로 벌려 구분력을 지킨다.

| 카테고리 | 뱃지 바탕 | 뱃지 글자 | 지도 점 | 고른 이유 |
|---|---|---|---|---|
| 주거 | `#DCE9FD` | `#1D4E9E` | `#3B79EA` | 하모 본색 — "진주에 머무는 것" |
| 일자리 | `#CFEAE8` | `#0E6B67` | `#12928C` | 남강 물빛 (하모가 사는 곳) |
| 문화 | `#E5DEFB` | `#56409F` | `#7B5FD1` | 유등 보랏빛 |
| 커뮤니티 | `#FBDCE3` | `#A63757` | `#D9557A` | 하모 볼·조개의 산호빛 |

주거 뱃지 바탕이 `hamo-100`과 같은 값인 것은 의도다. 뱃지는 **연한 바탕 + 진한 글자**, 주 버튼은 **꽉 찬 바탕 + 흰 글자**로 형태가 달라서 브랜드색과 주거 뱃지가 헷갈리지 않는다.

D-day 뱃지는 카테고리 색을 쓰지 않는다 — 급한 것(7일 이하)은 `rose-500` 바탕에 흰 글자, 그 외(`상시`/`마감`/`D-14`)는 `slate-100` 바탕에 `slate-500` 글자.

### 4.4 글꼴

- 본문·UI: **IBM Plex Sans KR** (400 / 500 / 700)
- 숫자·D-day: **IBM Plex Mono** (500 / 600) — 자리수가 흔들리지 않는다
- `next/font/google`로만 불러온다. **새 라이브러리를 추가하지 않는다**
- `<html lang="ko">` — 한글 사이트다

고른 이유: 휴머니스트 계열이라 아래 "친근·캐주얼" 톤에 맞고, 만화 같지 않아 정책 정보의 신뢰도 함께 지킨다.

### 4.6 모서리·그림자

모서리는 3개만 쓴다.

- **16px** — 카드, 6하원칙 블록, 지도, 온보딩 패널, 빈 상태
- **10px** — 모든 입력창, 목록 행, 썸네일, 후기
- **완전한 알약** — 버튼, 칩, 뱃지, 찜 버튼

그림자는 2개만 쓴다. 회색이 아니라 `hamo-900`을 옅게 섞어 화면에 붙게 한다.

- 평소: `0 1px 2px rgb(23 50 95 / 0.04), 0 1px 3px rgb(23 50 95 / 0.06)`
- hover: `0 4px 12px rgb(23 50 95 / 0.10)`

### 4.7 버튼 4종 × 2크기

이 조합 밖의 버튼을 새로 만들지 않는다.

| 종류 | 평소 | hover | 쓰는 곳 |
|---|---|---|---|
| 주 버튼 | `hamo-600` 바탕 / 흰 글자 | `hamo-700` | 신청 바로가기, 게시하기, 참여하기, 로그인 |
| 보조 버튼 | 흰 바탕 / `slate-300` 테두리 / `slate-700` 글자 | `slate-50` 바탕 | 취소, 참여 취소하기, 조건 바꾸기 |
| 약한 버튼 | `hamo-100` 바탕 / `hamo-700` 글자 | `hamo-200` | 건너뛰기 같은 낮은 우선순위 |
| 위험 버튼 | 바탕 없음 / `rose-600` 글자 | `rose-50` 바탕 | 삭제하기 |

- 크기: **작게** 36px 높이 / 14px 글자, **크게** 44px 높이 / 15px 글자
- 잠긴 상태는 투명도 40% + 클릭 불가. `마감`처럼 상태를 보여줘야 할 때는 `slate-100` 바탕 / `slate-500` 글자
- 모바일에서 손가락으로 누르는 주 버튼은 **크게**를 쓴다 (0절의 44px 규칙과 같은 이유)

### 4.8 진주 알 (시그니처)

하모의 왕진주 목걸이에서 따온 **6px 하모 원 + 왼쪽 위 흰 점 하나.** 딱 세 곳에만 쓴다.

1. 하단탭 활성 표시 (아이콘 아래)
2. 섹션 제목 앞
3. 지도에서 강조된 공간

**그 외 어디에도 쓰지 않는다.** 여러 곳에 흩뿌리면 시그니처가 아니라 장식이 된다.

### 4.9 아이콘

- 하단탭 4개, 찜 하트(채움/빈), 화살표, 검색, 닫기는 **인라인 SVG**. `currentColor`를 쓰고 `aria-hidden`을 붙인다
- **카테고리 사진 자리의 이모지(🏠 💼 🎨 🤝)는 유지한다** — 아이콘이 아니라 사진 대신이고, 실제 사진이 준비되면 사라진다
- 아이콘 라이브러리를 설치하지 않는다

### 4.10 말투 (2026-08-07, 폐기된 별도 기획 문서에서 이관)

- **모바일 우선.** 심사위원은 휴대폰으로 본다. PC는 가운데 정렬된 좁은 폭이면 충분하다
- **톤은 친근·캐주얼.** 관공서 문체를 쓰지 않는다
- **한 줄 요약은 이 서비스의 심장이다.** 30자 내외로, 관공서 문장을 이 톤으로 번역해서 쓴다
- 버튼 이름은 **누르면 무슨 일이 일어나는지**로 적는다 (`제출` 대신 `게시하기`)
- 같은 행동은 화면이 바뀌어도 같은 이름으로 부른다
- 빈 화면은 **안내문 + 다음에 할 행동**을 함께 준다. 사과하지 않고, 무엇이 없는지 분명히 말한다

### 4.11 지켜야 할 최소선

- **다크모드는 만들지 않는다.** 라이트 한 가지만 제대로 한다 (2026-08-07 결정 — 절반만 적용된 다크 스타일을 걷어냄)
- 모든 버튼·링크·입력창에 **키보드 포커스 표시**가 보여야 한다. `outline-none`으로 지우지 않는다
- 글자와 바탕의 대비는 **4.5:1 이상**
- `prefers-reduced-motion`을 켠 사용자에게는 전환 효과를 끈다
- 폭 **390px**(아이폰)에서 가로 스크롤이 생기지 않아야 한다
