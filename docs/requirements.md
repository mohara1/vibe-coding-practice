# 요구사항 명세 — 잇다

## 0. 탭 내비게이션 (2026-08-06 변경)
- 탭 버튼은 화면 **하단**에 고정 (기존 상단 → 하단)
- 탭 이름: **정보** (기존 "홈"), **공간** (기존 "장소")
- 모바일에서 누르기 쉽도록 버튼 크기를 키움 (슥삭 스타일 참고)

## 1. 화면 목록

### 정보탭 (`/`)
- 정책 카드와 공간 카드가 섞인 목록
- 관심사 태그 필터 (주거 / 일자리 / 문화 / 커뮤니티)
- **신분 필터** (전체 / 대학생 / 직장인) — 선택하면 정책 카드 중 해당 신분에 추천되는 것만 보임. 공간 카드는 신분 필터의 영향을 받지 않음 (2026-08-06 추가)
- 카드에는 제목, 카테고리 태그, 한 줄 요약이 보임
- 카드를 누르면 종류에 따라 정책 상세 또는 공간 상세로 이동

### 정책 상세 화면
- 정책 제목
- 카테고리 태그
- 상세 설명
- 신청 바로가기 링크(버튼)
- 홈으로 돌아가는 버튼

### 공간 상세 화면
- 공간 이름
- 카테고리 태그
- **사진** (실제 사진이 없으면 카테고리 아이콘 플레이스홀더로 대체) (2026-08-06 추가)
- 소개 설명
- 모의 지도 위치 표시 (해당 공간 위치를 강조)
- 후기 목록 (작성자, 내용)
- 정보탭으로 돌아가는 버튼

### 공간탭 (`/places`) (기존 "장소 탭"에서 이름 변경, 2026-08-06)
- 검색창 — 기관 이름으로 검색
- 관심사 태그 필터 (주거 / 일자리 / 문화 / 커뮤니티)
- 모의 지도 — 필터링된 공간(기관)을 지도 위 위치에 표시. 각 위치를 누르면 공간 상세로 이동
- 지도 아래 목록 — 필터링된 공간을 사진과 함께 리스트로도 보여줌 (지도가 익숙하지 않은 사용자를 위한 대안)

## 2. 기능 목록 (사용자가 할 수 있는 행동)

- 정보탭에서 정책/공간 카드 목록 보기
- 관심사 태그를 눌러 카드 목록 필터링하기
- **신분(대학생/직장인)을 선택해 추천 정책만 보기** (2026-08-06 추가)
- 정책 카드를 눌러 정책 상세 화면으로 이동하기
- 공간 카드를 눌러 공간 상세 화면으로 이동하기
- 정책 상세에서 신청 바로가기 링크를 눌러 외부 페이지로 이동하기
- 공간 상세에서 지도로 위치 확인하기
- 공간 상세에서 사진과 등록된 후기 보기
- 상세 화면에서 정보탭으로 돌아가기
- 하단 탭으로 정보/공간 화면 사이를 이동하기
- 공간탭에서 기관 이름으로 검색하기
- 공간탭에서 관심사 태그로 지도 위 표시를 필터링하기
- 공간탭 지도에서 위치를 눌러 공간 상세로 이동하기

## 4. 이번에 만들지 않을 것

- 로그인 / 회원가입
- 관리자 페이지 (정책·공간 데이터를 등록/수정하는 기능)
- 사용자가 직접 후기를 작성하는 기능 (후기는 예시 데이터로만 표시)
- 채팅, 모임 매칭 등 커뮤니티 기능
- 정책 데이터 자동 수집(크롤링) — 지금은 하드코딩된 예시 데이터만 사용
- 실제 지도 API(카카오맵 등) 연동 — 지금은 상대 좌표 기반 모의 지도로 대체 (2026-08-06 변경)
- 공간 실제 사진 촬영/업로드 — 지금은 카테고리 아이콘 플레이스홀더만 사용, 실제 사진은 파일이 준비되면 교체 (2026-08-06 추가)
- 신분(대학생/직장인) 선택값 저장 — 매번 다시 선택. localStorage 등에 저장하지 않음 (2026-08-06 추가)
- 버스 기사 평가, 열차 노선 등 오늘 범위 밖의 다른 아이디어
