## 1. 화면 목록

### 정보탭 (`/`)
- 우측 상단: **로그인 버튼**, 그 아래 **검색창** — "청년", "월세" 같은 키워드로 제목·요약·설명을 검색 (2026-08-06 추가)
- **3초 온보딩 오버레이** (첫 방문 시 자동 표시, 2026-08-06 추가) — 아래 "온보딩 오버레이" 참고. 완료하면 `24살 · 진주 거주 · 대학생 기준으로 보는 중` 형태의 **내 조건 배너**가 검색창 아래에 나타나고, 배너의 `조건 바꾸기`로 다시 열 수 있음
  - 기존에 있던 "나는 지금 [대학생/직장인]" 칩은 온보딩으로 대체되어 제거됨
- 정책 카드와 공간 카드가 섞인 목록
- 관심사 태그 필터 (주거 / 일자리 / 문화 / 커뮤니티)
- 온보딩에서 신분을 선택했다면, 정책 카드 중 해당 신분에 추천되는 것만 보임. 공간 카드는 영향받지 않음
- 카드에는 사진(또는 플레이스홀더), **찜(하트) 버튼**, 제목, 카테고리 태그, 한 줄 요약이 보임. **정책·공간 카드 모두 제목 옆에 D-day 뱃지**를 보여줌 — 공간은 실제 마감 개념이 없어 임의의 날짜로 표시 (의미 없는 장식용). `/공간탭` 목록 카드에는 D-day를 적용하지 않음
  - **찜 버튼은 로그인이 필요함** (2026-08-06 변경) — 로그인 안 한 상태로 누르면 찜되지 않고 마이탭(로그인 화면 역할)으로 이동함
- 검색/필터 결과가 0건이면 "검색 결과가 없어요" 안내 표시
- 카드를 누르면 종류에 따라 정책 상세 또는 공간 상세로 이동

### 3초 온보딩 오버레이 (2026-08-06 추가, docs2 S3 참고)
- 첫 방문 시 자동으로 뜨는 오버레이 (별도 페이지 아님)
- 문항: **나이대**(19-24 / 25-29 / 30-34) · **진주에 살아요?**(네 / 아니요) · **지금 뭐 해요?**(대학생 / 직장인 / 구직중)
- 하단 버튼: `건너뛰기`(항상 노출) · `완료`
- 건너뛰어도 전체 목록은 그대로 보임 — 막는 화면 아님
- 완료/건너뛰기 하면 localStorage에 저장되어 다시 뜨지 않음. 정보탭의 `조건 바꾸기` 또는 마이탭의 `조건 바꾸기`로만 다시 열림
- "진주에 살아요?" 응답은 저장은 하지만, 현재 데이터가 전부 진주시 정책이라 실제 필터링에는 반영하지 않음 (나이대·신분만 추천 로직에 사용)

### 정책 상세 화면 (2026-08-06 대폭 개편)
- 카테고리 태그 옆 **찜(하트) 버튼** (2026-08-06 추가)
- 정책 제목 옆 **마감 D-day 뱃지**
- 카테고리 태그, 한 줄 요약
- **6하원칙 블록** — 누가(대상) / 언제(신청·사업 기간) / 어디서(신청 장소·주관 기관) / 무엇을(지원 내용) / 어떻게(신청 방법) / 왜(정책 목적)
- 신청 바로가기 링크(버튼)
- 정보탭으로 돌아가는 버튼
- 사진 영역 없음 — 정책 상세에서는 사진을 보여주지 않음 (2026-08-06 변경: 카드 목록의 썸네일과 공간 상세의 사진은 유지, 정책 상세만 제외)

### 공간 상세 화면 (2026-08-06 대폭 개편)
- 모의 지도 위치 표시 (해당 공간 위치를 강조, 실제 지도 이미지 배경 위에 표시) — 사진보다 **위쪽**에 배치 (2026-08-06 위치 변경)
- 카테고리 태그 옆 **찜(하트) 버튼** (2026-08-06 추가)
- 공간 이름, 카테고리 태그
- **6하원칙 블록** — 누가(주요 이용자) / 언제(운영시간) / 어디서(위치) / 무엇을(제공하는 것) / 어떻게(이용 방법) / 왜(방문 이유)
- **사진** (실제 사진이 없으면 카테고리 아이콘 플레이스홀더로 대체) — 6하원칙 블록과 후기 사이에 배치 (2026-08-06 위치 변경)
- 후기 목록 (작성자, 내용)
- 정보탭으로 돌아가는 버튼

### 공간탭 (`/places`) (기존 "장소 탭"에서 이름 변경, 2026-08-06)
- 검색창 — 기관 이름으로 검색
- 관심사 태그 필터 (주거 / 일자리 / 문화 / 커뮤니티)
- 모의 지도 — **진주 지역 실제 지도 이미지를 배경으로 깔고**, 그 위에 필터링된 공간(기관) 점을 표시. 각 위치를 누르면 공간 상세로 이동 (2026-08-06 변경)
  - 참고: 지도 이미지는 배경 그림일 뿐, 점의 위치는 실제 GPS 좌표와 정확히 일치하지 않는 모의 배치임
- 지도 아래 목록 — 필터링된 공간을 사진과 함께 **찜 버튼**을 포함한 리스트로도 보여줌 (지도가 익숙하지 않은 사용자를 위한 대안, 2026-08-06 찜 버튼 추가) — 이 목록의 카드에는 D-day를 표시하지 않음

### 마이탭 (`/my`) (2026-08-06 신규)
- 로그인 안 했을 때: "로그인하면 내 정보와 찜한 목록을 볼 수 있어요" 안내 + 로그인 버튼만 표시
- 로그인 했을 때:
  1. **모의 사용자 이름** — 실제 계정이 아니라 로그인 시 랜덤으로 배정되는 닉네임 (예: "진주달빛청년")
  2. **내 정보** — 온보딩으로 얻은 나이대·거주·신분 요약 + `조건 바꾸기` 버튼 (누르면 정보탭 온보딩 오버레이가 다시 열림)
  3. **추천 정책 4개** — 내 신분에 맞는 정책 중 4개 (신분 미설정 시 상위 4개로 대체)
  4. **찜한 목록** — 찜한 정책·공간을 모두 카드로 보여줌. 없으면 "아직 찜한 게 없어요" 안내

## 2. 기능 목록 (사용자가 할 수 있는 행동)

- 정보탭에서 정책/공간 카드 목록 보기
- 우측 상단 검색창에 키워드를 입력해 카드 검색하기
- 관심사 태그를 눌러 카드 목록 필터링하기
- **3초 온보딩에 답하거나 건너뛰기** (2026-08-06 추가) — 답하면 나이대·거주·신분이 저장되고 정책 추천에 반영됨
- **내 조건 배너의 `조건 바꾸기`로 온보딩 다시 열기** (2026-08-06 추가)
- **검색창 옆 로그인 버튼으로 모의 로그인/로그아웃하기** (2026-08-06 추가)
- **카드·상세 화면의 하트 버튼으로 정책·공간을 찜하거나 찜 해제하기** (2026-08-06 추가). 로그인 안 한 상태면 하트를 눌렀을 때 찜 대신 마이탭으로 이동함 (2026-08-06 변경)
- 정책 카드를 눌러 정책 상세 화면으로 이동하기
- 공간 카드를 눌러 공간 상세 화면으로 이동하기
- 정책 상세에서 신청 바로가기 링크를 눌러 외부 페이지로 이동하기
- 공간 상세에서 지도로 위치 확인하기
- 공간 상세에서 사진과 등록된 후기 보기
- 상세 화면에서 정보탭으로 돌아가기
- 하단 탭으로 정보/공간/**마이** 화면 사이를 이동하기 (2026-08-06 마이 추가)
- 공간탭에서 기관 이름으로 검색하기
- 공간탭에서 관심사 태그로 지도 위 표시를 필터링하기
- 공간탭 지도에서 위치를 눌러 공간 상세로 이동하기
- **마이탭에서 로그인 후 내 정보·추천 정책 4개·찜한 목록 보기** (2026-08-06 추가)

## 4. 이번에 만들지 않을 것

- **실제 로그인/회원가입** — 이메일·비밀번호·본인인증 없음. 버튼을 누르면 랜덤 닉네임이 배정되는 **모의 로그인**만 있음. 서버에 계정을 저장하지 않고 브라우저(localStorage)에만 남음 (2026-08-06 변경: 완전 배제 → 모의 로그인으로 축소)
- 서버·DB — Supabase 등 백엔드를 붙이지 않음. 로그인·온보딩·찜 모두 localStorage로 처리
- 관리자 페이지 (정책·공간 데이터를 등록/수정하는 기능)
- 사용자가 직접 후기를 작성하는 기능 (후기는 예시 데이터로만 표시)
- 채팅, 모임 매칭 등 커뮤니티 기능
