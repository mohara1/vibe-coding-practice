# 요구사항 명세 — 잇다

## 0. 탭 내비게이션 (2026-08-06 변경)
- 탭 버튼은 화면 **하단**에 고정 (기존 상단 → 하단)
- 탭 이름: **정보** (기존 "홈"), **공간** (기존 "장소")
- 모바일에서 누르기 쉽도록 버튼 크기를 키움 (슥삭 스타일 참고)

## 1. 화면 목록

### 정보탭 (`/`)
- **우측 상단 검색창** — "청년", "월세" 같은 키워드로 제목·요약·설명을 검색 (2026-08-06 추가)
- 정책 카드와 공간 카드가 섞인 목록
- 관심사 태그 필터 (주거 / 일자리 / 문화 / 커뮤니티)
- **신분 필터** (전체 / 대학생 / 직장인) — 선택하면 정책 카드 중 해당 신분에 추천되는 것만 보임. 공간 카드는 신분 필터의 영향을 받지 않음 (2026-08-06 추가)
- 카드에는 사진(또는 플레이스홀더), 제목, 카테고리 태그, 한 줄 요약이 보임. 정책 카드는 제목 옆에 **마감 D-day 뱃지**도 함께 보임 (2026-08-06 추가)
- 검색/필터 결과가 0건이면 "검색 결과가 없어요" 안내 표시 (2026-08-06 추가)
- 카드를 누르면 종류에 따라 정책 상세 또는 공간 상세로 이동

### 정책 상세 화면 (2026-08-06 대폭 개편)
- 정책 제목 옆 **마감 D-day 뱃지**
- 카테고리 태그, 한 줄 요약
- **6하원칙 블록** — 누가(대상) / 언제(신청·사업 기간) / 어디서(신청 장소·주관 기관) / 무엇을(지원 내용) / 어떻게(신청 방법) / 왜(정책 목적)
- 신청 바로가기 링크(버튼)
- 정보탭으로 돌아가는 버튼
- 사진 영역 없음 — 정책 상세에서는 사진을 보여주지 않음 (2026-08-06 변경: 카드 목록의 썸네일과 공간 상세의 사진은 유지, 정책 상세만 제외)

### 공간 상세 화면 (2026-08-06 대폭 개편)
- 공간 이름, 카테고리 태그
- **사진** (실제 사진이 없으면 카테고리 아이콘 플레이스홀더로 대체)
- **6하원칙 블록** — 누가(주요 이용자) / 언제(운영시간) / 어디서(위치) / 무엇을(제공하는 것) / 어떻게(이용 방법) / 왜(방문 이유)
- 모의 지도 위치 표시 (해당 공간 위치를 강조, 실제 지도 이미지 배경 위에 표시)
- 후기 목록 (작성자, 내용)
- 정보탭으로 돌아가는 버튼

### 공간탭 (`/places`) (기존 "장소 탭"에서 이름 변경, 2026-08-06)
- 검색창 — 기관 이름으로 검색
- 관심사 태그 필터 (주거 / 일자리 / 문화 / 커뮤니티)
- 모의 지도 — **진주 지역 실제 지도 이미지를 배경으로 깔고**, 그 위에 필터링된 공간(기관) 점을 표시. 각 위치를 누르면 공간 상세로 이동 (2026-08-06 변경)
  - 참고: 지도 이미지는 배경 그림일 뿐, 점의 위치는 실제 GPS 좌표와 정확히 일치하지 않는 모의 배치임
- 지도 아래 목록 — 필터링된 공간을 사진과 함께 리스트로도 보여줌 (지도가 익숙하지 않은 사용자를 위한 대안)

## 2. 기능 목록 (사용자가 할 수 있는 행동)

- 정보탭에서 정책/공간 카드 목록 보기
- **우측 상단 검색창에 키워드를 입력해 카드 검색하기** (2026-08-06 추가)
- 관심사 태그를 눌러 카드 목록 필터링하기
- **신분(대학생/직장인)을 선택해 추천 정책만 보기** (2026-08-06 추가)
- 정책 카드를 눌러 정책 상세 화면으로 이동하기
- 공간 카드를 눌러 공간 상세 화면으로 이동하기
- 정책 상세에서 신청 바로가기 링크를 눌러 외부 페이지로 이동하기
- 공간 상세에서 지도로 위치 확인하기
- 공간 상세에서 사진과 등록된 후기 보기
- 상세 화면에서 정보탭으로 돌아가기
- 하단 탭으로 정보/공간 화면 사이를 이동하기
- 공간탭에서 기관 이름으로 검색하기
- 공간탭에서 관심사 태그로 지도 위 표시를 필터링하기
- 공간탭 지도에서 위치를 눌러 공간 상세로 이동하기

**D-day 뱃지 규칙 (계산값, 저장하지 않음):**
- `applyEnd`가 null → 회색 네모 `상시`
- 마감일이 지났으면 → 회색 네모 `마감`
- 오늘부터 마감일까지 남은 일수가 **7일 이하** → 빨간 네모 `D-3` 등
- 8일 이상 남았으면 → 회색 네모 `D-14` 등
